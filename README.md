# matstat-notes

Конспект лекций по математической статистике в LaTeX. 

**[Скачать свежий PDF](https://github.com/atelitsin/matstat-notes/releases/download/latest/matstat_lecture_notes_2026.pdf)** — собирается автоматически при каждом пуше в `main`.

## Важно

Это **неофициальный** конспект, написанный студентами по их записям лекций
и учебнику Буре В.М, Парилиной Е.М «Теория вероятностей и математическая статистика», при подготовке использовались ИИ-инструменты. Лектор конспект не проверял и не утверждал.

- В тексте возможны ошибки, неточности и пропуски. Конспект не заменяет
  лекции, учебник и требования преподавателя.
- Если конспект расходится с лекцией или учебником, верными считайте
  лекцию и учебник — и, пожалуйста, сообщите об ошибке через issue.
- Материал предоставляется «как есть». Составители не несут ответственности
  за результаты экзаменов и зачётов и за любые другие последствия
  его использования.

## Структура

```
main.tex            главный файл: подключает преамбулу и лекции
preamble/
  packages.tex      пакеты
  macros.tex        обозначения: \E, \D, \Pt, \Xbar, \toP, \tod, \Norm, ...
  theorems.tex      окружения theorem / definition / example, keybox, reminder, addendum
lectures/lecNN.tex  по файлу на лекцию (без преамбулы, начинается с \section)
latexmkrc           настройки сборки (результат в build/)
```

## Сборка

```bash
latexmk            # собрать build/main.pdf
latexmk -pvc       # пересобирать при каждом сохранении
latexmk -c         # удалить вспомогательные файлы
```

Чтобы быстро собирать только текущую лекцию, раскомментируйте в `main.tex`
строку `\includeonly{lectures/lecNN}`.

## Новая лекция

1. Скопируйте `lectures/_template.tex` в `lectures/lecNN.tex` и замените содержимое.
   Шаблон показывает все окружения, макросы и приёмы оформления; в сборку он не входит.
2. Добавьте `\include{lectures/lecNN}` в `main.tex`.
3. Коммит: `lecNN: тема лекции`.
